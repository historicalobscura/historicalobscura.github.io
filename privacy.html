Privacy Policy

Last updated: November 19, 2026

yt-auto is a private tool used by the owner of the YouTube channel Historical Obscura to publish and manage that channel's own videos. This policy explains what data the tool accesses and how it is handled.

YouTube API Services

yt-auto uses YouTube API Services. By using yt-auto you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data accessed

With the account holder's permission (Google OAuth), yt-auto accesses:

  • basic channel information (channel name, statistics),
  • the channel's own videos and their metadata, in order to upload, schedule and update them,
  • the channel's own YouTube Analytics reports (views, impressions, watch time).

yt-auto does not access any other user's data, comments, subscribers' personal information, or private messages.

How data is used and stored

  • Data is used only to publish the channel's videos and to plan future content.
  • The OAuth access token and analytics reports are stored only on the channel owner's personal computer. They are not uploaded to any server operated by yt-auto.
  • Data is never sold, shared with third parties, or used for advertising.

Retention and deletion

Analytics reports are kept locally only as long as needed for content planning. The account holder can revoke yt-auto's access at any time from the Google security settings page; locally stored tokens are deleted when access is revoked or on request.
